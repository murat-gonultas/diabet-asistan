# Roadmap - Diabet Asistan

## Phase 0 - Product and Safety Foundation

Goal: Define product boundaries before writing production code.

Deliverables:

- Product vision.
- MVP scope.
- Safety boundaries.
- No-insulin-dosing policy.
- Risk register.
- Initial Kanban board.

## Phase 1 - Backend Core MVP

Goal: Create the Spring Boot backend for the safe meal logging workflow.

Deliverables:

- Spring Boot project.
- Family management.
- User management.
- Meal records.
- Parent review workflow.
- Family recipes.
- Validation.
- Tests.

## Phase 2 - Flutter Mobile MVP

Goal: Build the first mobile app for real family testing.

Deliverables:

- Flutter project.
- Child mode.
- Parent mode.
- Create meal screen.
- Meal history.
- Parent review screen.
- Family recipe screens.
- Local photo handling.

## Phase 3 - Family Test Version

Goal: Use the app safely inside the family.

Deliverables:

- Manual test scenarios.
- Realistic demo data.
- Basic UI polish.
- Safe warnings.
- Meal history review.
- At least 20 real meal records.

## Phase 4 - AI-Assisted Prototype

Goal: Add AI as an assistant, not as an authority.

Deliverables:

- AI adapter service.
- Food candidate detection.
- Carbohydrate range estimation.
- Confidence level.
- Parent correction loop.
- Dataset preparation for later evaluation.

## Phase 5 - Dexcom-Based Meal Impact Analysis

Goal: Analyze what happens after meals.

Deliverables:

- Dexcom OAuth integration.
- CGM reading import.
- Meal-to-glucose time window matching.
- Post-meal glucose trend report.
- Meal impact history.

## Phase 6 - Research and Clinical Pilot Readiness

Goal: Prepare a faculty-level research prototype.

Deliverables:

- Research protocol draft.
- Consent model.
- Pseudonymized dataset export.
- Accuracy evaluation.
- Usability evaluation.
- Ethics committee preparation.

## Phase 7 - Productization

Goal: Prepare for broader user testing or commercial strategy.

Deliverables:

- Strong authentication.
- GDPR-ready privacy workflow.
- Production hosting.
- Monitoring.
- Terms and privacy policy.
- Partner/investor presentation.
